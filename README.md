# LessonPaint

静的ホスティング向けのペイントアプリ MVP v2 実装です。

## 起動

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開いてください。

## 主要機能

- オフスクリーン canvas レイヤー + 合成表示
- Undo/Redo 履歴（確定操作単位）
- ペン / エアブラシ / 消しゴム / 塗りつぶし / 直線 / 矩形 / 円 / 多角形
- 矩形選択 + 選択範囲移動（確定で履歴化）
- レイヤー追加・削除・並べ替え(D&D)・可視・不透明度・合成モード
- 画像読み込み（新規レイヤー化）
- PNG 書き出し
- 2本指ピンチズーム＆パン
- Apple Pencil 優先入力（touch 描画禁止）
